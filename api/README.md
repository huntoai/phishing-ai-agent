# API Directory

This directory contains backend API implementations for the phishing awareness website.

## Structure

- `scam-report/` - API endpoints for scam reporting functionality
- `awareness-training/` - API endpoints for awareness training system
- `scam-encyclopedia/` - API endpoints for scam information and search

## Implementation Status

⚠️ **To be implemented** - These directories are placeholders for future backend implementation.

## Planned Features

### Scam Report API
- Submit scam reports
- Check report status
- Get guidance on next steps (govt/bank reporting)
- Track report analytics

### Awareness Training API
- Sync local storage data with backend
- Track user progress
- Deliver drip content to WhatsApp and other channels
- Manage courses and learning modules

### Scam Encyclopedia API
- Search and filter scam information
- Retrieve detailed scam explanations
- Get related scam types
- Analytics on most viewed/searched scams
